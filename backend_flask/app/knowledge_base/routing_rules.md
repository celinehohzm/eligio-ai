# Johns Hopkins Neurology — Routing Rules
## Distilled from the Hopkins Patient Access Services Decision Tree

This document captures the clinical routing logic used by Johns Hopkins Neurology
to route new patients to the correct subspecialty clinic. Use this as the primary
reference when making subspecialty routing recommendations.

---

## How to Use These Rules

When routing a referral, identify the patient's primary symptom category first,
then apply the relevant rules below. If a patient's presentation spans multiple
categories, escalate for physician review rather than guessing.

---

## Subspecialty Clinics and Their Routing Criteria

### 1. Movement Disorders / Parkinson's Disease Center

**Route here for:**
- Parkinson's Disease (PD)
- Essential Tremor (ET)
- Dystonia (cervical dystonia, generalized dystonia, hemidystonia)
- Atypical Parkinsonism: Corticobasal Degeneration (CBD), Corticobasal Syndrome (CBS),
  Multiple System Atrophy (MSA), Progressive Supranuclear Palsy (PSP),
  Shy-Drager Syndrome, Secondary Parkinsonism, Parkinson Plus Syndromes
- Lewy Body Dementia (LBD)
- Dyskinesia, Tardive Dyskinesia (TD)
- Functional Movement Disorder (FMD) — requires specific referral to FMD Clinic
- Myoclonus
- Hemifacial Spasm (HFS), Blepharospasm, Sialorrhea
- Tic Disorder, Tourette's Syndrome
- Wilson's Disease
- Spasticity
- Restless Leg Syndrome (RLS) — also acceptable under Sleep
- Torticollis, Spasmodic Torticollis
- Choreas (non-Huntington's) — Huntington's routes to Huntington's Disease Center
- Paroxysmal Movement Disorders
- Tremors (unspecified), Unspecified Movement Disorder
- Abnormal Involuntary Movements (AIM)
- Procedures: Botox injections, Deep Brain Stimulation (DBS) evaluation, Duopa

**Key discriminating signals:**
- Tremor at rest (pill-rolling) → strongly suggests Parkinson's
- Action tremor only, family history → suggests Essential Tremor
- Slow movement (bradykinesia) + rigidity → Movement Disorders
- Involuntary, uncontrolled movements → Movement Disorders
- Onset typically chronic (months to years), not acute

**Prior evaluation required:** Yes — patient must have been evaluated by a PCP
or other specialist before referral. Self-referrals without prior evaluation are
denied for most movement disorder diagnoses.

**Record requirements:** Last 3 clinical notes + MRI reports if applicable.
Some diagnoses require referral triage review before scheduling.

### 2. Epilepsy Center

**Route here for:**
- Epilepsy (general, intractable, drug-resistant)
- Seizures (possible seizures, first-time seizure, recurrent seizures)
- Convulsions, Grand Mal / Tonic-Clonic Seizures
- Petit Mal / Absence Seizures
- Psychogenic Nonepileptic Seizures (PNES) / Pseudo Seizures
- Pregnancy and Epilepsy
- Epilepsy surgical candidate evaluation
- Ketogenic diet / Modified Atkins Diet for epilepsy
- Neurostimulator adjustment: VNS, RNS, DBS (epilepsy indication)
- Seizures with Brain Tumor

**First-time seizure sub-pathway:**
- First seizure within the last 14 days + not previously seen by neurology →
  First Time Seizure clinic (NP visit)
- First seizure + already evaluated by neurologist in ED or outpatient → General Epilepsy
- If patient has had similar episodes before → General Epilepsy

**Key discriminating signals:**
- Episodic loss of consciousness + post-ictal confusion → Epilepsy
- Convulsions, jerking movements → Epilepsy
- Staring spells, absence episodes → Epilepsy
- EEG abnormalities documented → Epilepsy
- Distinguish from syncope: syncope routes to Cardiology first
- Distinguish from TIA: if concern for vascular etiology, route to Cerebrovascular

**Record requirements:** Last 3 clinical notes + MRI and EEG reports.
General Epilepsy records required at least 14 days before appointment.
Surgical candidate records required at least 14 days before appointment.

### 3. Stroke and Cerebrovascular Neurology

**Route here for:**
- Stroke (ischemic, hemorrhagic)
- Transient Ischemic Attack (TIA)
- Cerebrovascular Accident (CVA)
- Brain Bleed, Brain Hemorrhage, Intracerebral Hemorrhage,
  Intracranial Hemorrhage, Subarachnoid Hemorrhage
- Carotid Stenosis, Carotid Artery Dissection
- Vertebral Artery Disease, Vertebral Artery Dissection
- Arteriovenous Malformation (AVM) — may also need Neurosurgery
- Cerebral Aneurysm — refer to Neurosurgery first if unseen by neurosurgeon
- Moya Moya Disease
- Cerebral Venous Sinus Thrombosis (CSVT)
- CADASIL (Cerebral Autosomal Dominant Arteriopathy)
- Cerebral Vasculitis, Central Nervous System Vasculitis (CNSV)
- Microvascular Ischemia on MRI
- Cerebral Small Vessel Disease (CSVD)
- Aphasia / Dysphasia (speech or language issue) related to stroke
- Primary Progressive Aphasia (if stroke-related)
- Sickle Cell Disease with Stroke or TIA
- Stroke Prevention
- Superficial Siderosis (SS) — routes to specific provider (Llinas)
- Amaurosis Fugax (Transient Vision Loss) — if concern for TIA/stroke
- Vision loss or change in vision — if referring provider suspects stroke/TIA

**Critically important routing rule — episodic unilateral weakness:**
Episodic, unilateral focal deficits (weakness, sensory loss, speech difficulty,
vision loss) that fully resolve within minutes to hours = TIA until proven otherwise.
This is a CEREBROVASCULAR presentation, NOT Neuromuscular.
Patient age >50, hypertension, diabetes, atrial fibrillation, or other vascular
risk factors increase the likelihood of TIA and should increase routing confidence.
Mark as URGENT.

**Stroke within last 12 months:**
- Still seeking care → Cerebrovascular Clinic 1 (standard)
- Seeking stroke prevention or second opinion → Cerebrovascular Clinic 1

**Aneurysm / AVM:**
- If already seen by neurosurgeon → route to Cerebrovascular
- If NOT seen by neurosurgeon → route to Neurosurgery first

**Memory loss / confusion secondary to stroke:**
- If memory problems began after stroke → Cerebrovascular
- If memory problems NOT stroke-related → Memory Center / Cognitive Neurology

**Urgency:** Cerebrovascular referrals should be flagged urgent when:
- TIA within the last 48 hours
- Recent stroke (within 12 months) with new symptoms
- Acute visual loss
- Any acutely progressive neurological deficit

**Record requirements:** Referring physician note + MRI/MRA and CT or cerebrovascular
angiograms. Upload imaging to image sharing portal.
Records needed at least 7 days before appointment.

### 4. Headache Center

**Route here for:**
- Migraine (all types including vestibular migraine, hemiplegic migraine)
- Cluster Headache
- Tension-Type Headache (refractory or requiring specialist evaluation)
- Chronic Daily Headache
- New Daily Persistent Headache (NDPH)
- Trigeminal Neuralgia / Facial Pain
- Occipital Neuralgia
- Post-Traumatic Headache (PTH)
- Hemicrania Continua
- Sinus Headache (when primary headache disorder suspected)
- Atypical Facial Pain
- Post-Herpetic Neuralgia

**Important exclusions:**
- Opioids/narcotics/benzodiazepines: Headache Center cannot prescribe these.
  If patient is currently on them, they must agree to follow-up with prescribing
  provider or are denied.
- Concussion or head injury → route to Physical Medicine & Rehabilitation (PM&R),
  NOT Headache Center
- Headache with concurrent neurological disorder → may need triage review

**Key discriminating signals vs. Cerebrovascular:**
- Young patient, episodic, fully reversible, associated with visual aura → Headache
- Older patient, vascular risk factors, episodic unilateral weakness → Cerebrovascular
- "Thunderclap" headache (worst headache of life, sudden onset) → URGENT,
  rule out subarachnoid hemorrhage before routing

**Record requirements:** Adult Headache Questionnaire must be sent to patient
and returned before appointment. Records faxed at least 7 days prior.

### 5. Multiple Sclerosis and Neuroimmunology

**Route here for:**
- Multiple Sclerosis (MS) — all types: RRMS, PPMS, SPMS, possible MS
- Neuromyelitis Optica Spectrum Disorder (NMOSD)
- Myelin Oligodendrocyte Glycoprotein Associated Disorder (MOGAD)
- Optic Neuritis (acute, history of, or NMO-related)
- Transverse Myelitis (acute, partial, recurrent)
- Acute Disseminated Encephalomyelitis (ADEM)
- Autoimmune Encephalitis
- Demyelinating Disease / Demyelinating Myelopathy
- Leukoencephalopathy
- Lupus (neurological manifestations)
- Neurosarcoidosis / Sarcoidosis (neurological)
- Rare Neuroimmune Disorders
- Chronic Meningitis
- Paraneoplastic Encephalitis
- Myelopathy / Spinal Cord Disease (if demyelinating or autoimmune etiology)

**Subspecialty pathways within Neuroimmunology:**
- MS / Demyelinating Disease → Neuroimmunology 1
- Optic Neuritis (non-MOGAD, non-NMOSD) → Neuroimmunology 2
- ADEM, MOGAD, NMOSD → Neuroimmunology 3
- Myelopathy / Myelitis / Spinal Cord Disease → Neuroimmunology 3 or 4
- Neurosarcoidosis → Neurosarcoidosis Clinic
- Autoimmune Encephalitis → Encephalitis Clinic (Dr. Probasco)
- Stiff Person Syndrome → specific subspecialty referral required

**Required prior evaluation:** Patient must have been seen by a neurologist
or ophthalmologist before referral to Neuroimmunology. Self-referrals are denied.
Imaging (brain/spine MRI) must be completed before scheduling.

**Key discriminating signals:**
- Young patient, relapsing-remitting neurological symptoms → MS / Neuroimmunology
- Optic neuritis + MRI lesions → MS / Neuroimmunology
- Spinal cord symptoms + MRI lesions → MS / Neuroimmunology
- Spasticity with relapsing course → MS
- CSF findings (oligoclonal bands) → MS / Neuroimmunology

**Record requirements:** MRI brain + cervical + thoracic spine, lumbar puncture
results, relevant labwork. Records required 7 days before appointment.

### 6. Neuromuscular Medicine (Drachman Division)

**Route here for:**
- ALS (Amyotrophic Lateral Sclerosis) / Motor Neuron Disease
- Myasthenia Gravis (MG)
- Lambert-Eaton Myasthenic Syndrome (LEMS)
- Peripheral Neuropathy (diabetic, CIDP, GBS, CMT, small fiber, etc.)
- Myopathy (muscular dystrophy, inclusion body myositis, necrotizing myopathy)
- Guillain-Barré Syndrome (GBS)
- Spinal Muscular Atrophy (SMA)
- Primary Lateral Sclerosis (PLS)
- Post-Polio Syndrome
- Mitochondrial Disease
- Charcot-Marie-Tooth Disease (CMT)

**EMG requirement:** Most neuromuscular referrals require EMG/NCS to have been
completed before scheduling. Referrals without EMG are typically denied
(exception: motor neuron disease, SMA, some myopathies confirmed by biopsy).

**Key discriminating signals vs. other conditions:**
- Progressive bilateral proximal weakness → Neuromuscular (myopathy)
- Distal weakness + sensory symptoms (stocking-glove) → Neuromuscular (neuropathy)
- Fatigable weakness (worse with use, better with rest) → Neuromuscular (MG)
- Fasciculations + progressive weakness → Neuromuscular (ALS workup)
- NOT for acute unilateral weakness → that is Cerebrovascular

**Critical distinction:** The word "weakness" alone is not sufficient to route to
Neuromuscular. Key discriminating factors are:
- Bilateral vs. unilateral (bilateral → more likely Neuromuscular)
- Proximal vs. distal (proximal = myopathy; distal = neuropathy)
- Progressive vs. episodic (progressive → Neuromuscular; episodic → Cerebrovascular or Epilepsy)
- Associated sensory loss (stocking-glove distribution → peripheral neuropathy)

**Record requirements:** Last 3 clinical notes + MRI + relevant labwork + genetic
testing + EMG/NCS results. Records required 7-10 days for triage review.

### 7. Sleep Neurology

**Route here for:**
- Narcolepsy
- Insomnia (if not previously seen by Pulmonary Sleep — they take priority)
- Obstructive Sleep Apnea (if not pulmonary — Pulmonary Sleep takes priority)
- Restless Legs Syndrome (RLS) — also acceptable under Movement Disorders
- Parasomnias (REM Sleep Behavior Disorder, night terrors, sleepwalking)
- Periodic Limb Movement Disorder (PLMD)
- Hypersomnia
- Circadian Rhythm Disorders
- Daytime Sleepiness

**Important routing rule:** If patient has previously been seen by Pulmonary Sleep,
they are sent back to Pulmonary Sleep for continuity of care unless they
specifically request Neurology Sleep and have a referral.

**Opioids/benzodiazepines:** Sleep Center cannot prescribe these.

**Record requirements:** Last 3 clinical notes + all previous sleep studies.

### 8. Cognitive Neurology / Memory Center

**Route here for:**
- Alzheimer's Disease (age 50+ → Memory Center; age <50 → Young-Onset Dementias Clinic)
- Dementia (general, if age 55+ → Memory Center; if <55 → Young-Onset Dementias Clinic)
- Mild Cognitive Impairment (MCI)
- Frontotemporal Dementia (FTD) → Young-Onset Dementias Clinic (410-955-5147)
- Primary Progressive Aphasia (if cognitive/behavioral, not stroke-related)
- Memory Loss (age 50+)
- Confusion (if not vascular etiology)

**Age routing rules:**
- Age 55 or older → Memory Center at Bayview (410-550-6337)
- Age under 55 → Young-Onset Dementias Clinic (410-955-5147)
- If memory problems began after concussion/TBI → PM&R, NOT Memory Center
- If memory problems began after stroke → Cerebrovascular, NOT Memory Center

**Huntington's Disease:** Routes directly to Huntington's Disease Center (410-955-2398),
NOT to Movement Disorders or Memory.

---

### 9. Vestibular and Neuro-Visual Disorders

**Route here for:**
- Dizziness, Vertigo (chronic, > 6 months)
- Nystagmus
- Diplopia (Double Vision)
- Vision Loss, Change in Vision, Visual Disturbance (if not stroke-related)
- Amaurosis Fugax (if NOT concern for TIA — if TIA concern, route to Cerebrovascular)
- Ptosis
- Anisocoria (pupil problem)
- Unusual Eye Movements
- Gait Imbalance (if vestibular etiology)
- Visual Aura (if migraine-related and vestibular component)

**Important routing distinctions:**
- Dizziness < 6 months onset → may be acute and require urgent evaluation
- Dizziness > 6 months → standard vestibular clinic
- BPPV (Benign Paroxysmal Positional Vertigo) → routes to PM&R, NOT Vestibular
- Vision loss with concern for stroke/TIA → Cerebrovascular first
- Double vision from stroke → Cerebrovascular

**Requires prior evaluation:** By neuro-ophthalmologist for vision-related symptoms
unless acute onset.

---

### 10. Ataxia Center

**Route here for:**
- Ataxia (cerebellar, spinocerebellar, isolated gait ataxia)
- Spinocerebellar Ataxia (SCA)
- Friedreich's Ataxia (FA) → route to Muscular Dystrophy Association (MDA)
- Ataxia Telangiectasia (AT) → route to ATCC (410-614-1922)
- Cerebellar Degeneration / Atrophy on MRI

**If ataxia is due to stroke:** Route to Cerebrovascular, not Ataxia Center.
**If ataxia is due to MS:** Route to Neuroimmunology, not Ataxia Center.

**Genetic testing:** Ataxia Center requests genetic testing results if available.
If likely hereditary, age 25+ → Ataxia Center with genetic history pathway.

---

### 11. General Neurology

**Route here for:**
- Undifferentiated presentations that don't fit a subspecialty
- Numbness / Tingling (if < 6 months duration — if > 6 months, may qualify for subspecialty)
- Unspecified Weakness (general, without clear subspecialty features)
- Back / Neck Pain with neurological symptoms
- Radiculopathy, Sciatica, Pinched Nerve
- Facial Neuropathy, Other Cranial Neuropathy
- Muscle Cramps / Spasms
- General Neurology (catch-all)
- Functional Neurologic Disorder (FND) — specific FND clinic pathway
- Unlisted Diagnosis
- Dizziness (if not clearly vestibular)
- Post-hospital discharge follow-up (general)

**Important:** General Neurology requires prior PCP or specialist evaluation.
If patient has not been evaluated, they are asked to return to PCP first.
If symptoms began within 4 weeks, may qualify for expedited general neurology.

---

### 12. Physical Medicine & Rehabilitation (PM&R)

**Route here for (transfer out of Neurology):**
- Concussion, Traumatic Brain Injury (TBI)
- Post-Traumatic conditions
- Cerebral Palsy
- BPPV (Benign Paroxysmal Positional Vertigo)
- POTS (Postural Orthostatic Tachycardia Syndrome)
- Spasticity management / rehab therapy
- Back/neck pain with symptoms < 6 months and no prior neurologist evaluation

---

## Urgency Classification

**Emergent (same day / ED referral):**
- Active stroke symptoms
- Status epilepticus
- Thunderclap headache (rule out SAH)
- Rapidly progressive weakness affecting breathing or swallowing

**Urgent (within 1-2 weeks):**
- TIA within the last 48 hours
- First-time seizure within the last 14 days
- Newly diagnosed MS with acute symptoms
- Rapidly progressive neurological deficit
- Vestibular symptoms with new onset < 6 months
- Pediatric cerebrovascular conditions

**Routine (standard scheduling):**
- Established diagnoses seeking second opinion or transfer of care
- Chronic, stable conditions
- Outpatient follow-up

---

## Escalation Rules

Escalate for physician review (do not schedule without clinical approval) when:
- Confidence in routing is low (<65%) due to ambiguous presentation
- Symptoms span two subspecialties with no clear primary
- Active malignancy with new neurological symptoms
- Post-operative neurological complication
- Rapidly progressive course of any kind
- Referral document is too incomplete to extract reliable clinical data
- Patient has been referred to a specific named provider — honor that request
- Referral explicitly requests a specific subspecialty that differs from AI recommendation
- Movement Disorders: patient has NOT been previously evaluated by PCP or specialist
- Neuroimmunology: patient has NOT had imaging confirming diagnosis
- Neuromuscular: patient has NOT had EMG completed (exception: motor neuron disease)

## Records Required by Subspecialty

| Subspecialty | Required Records |
|---|---|
| Movement Disorders | Last 3 notes + MRI |
| Epilepsy (general) | Last 3 notes + MRI + EEG (14 days prior) |
| Epilepsy (first seizure) | ED notes + CT/MRI + EEG |
| Cerebrovascular | Referring note + MRI/MRA + CT or angiogram (7 days prior) |
| Headache | Adult Headache Questionnaire + records (7 days prior) |
| Neuroimmunology | MRI brain + spine + CSF results + labwork (7 days prior) |
| Neuromuscular | Last 3 notes + MRI + labwork + EMG/NCS (7-10 days) |
| Sleep | Last 3 notes + all prior sleep studies (7 days prior) |
| Cognitive/Memory | Last 3 notes + MRI + labwork + genetic testing if applicable |
| Ataxia | Last 3 notes + MRI + genetic testing if applicable (21 days prior) |
| Vestibular | Clinical notes + visual/vestibular/audiology testing + MRI/MRA |

## Key Routing Decision Points Summary

| Presentation | Route to |
|---|---|
| Tremor at rest + bradykinesia + rigidity | Movement Disorders |
| Action tremor only, family history | Movement Disorders (Essential Tremor) |
| Episodic unilateral weakness, fully resolving, minutes duration | Cerebrovascular (TIA) — URGENT |
| Progressive bilateral proximal weakness + elevated CK | Neuromuscular (myopathy) |
| Stocking-glove numbness/tingling + EMG done | Neuromuscular (neuropathy) |
| New seizure, any type | Epilepsy |
| Episodic loss of consciousness, post-ictal state | Epilepsy |
| Syncope | Cardiology first, not Neurology |
| Migraines, cluster headache, facial pain | Headache Center |
| Worst headache of life, sudden onset | URGENT — rule out SAH before routing |
| Young patient, relapsing neurological symptoms, MRI lesions | Neuroimmunology/MS |
| Optic neuritis | Neuroimmunology/MS |
| Transverse myelitis | Neuroimmunology/MS |
| Memory loss, age 55+ | Memory Center |
| Memory loss, age <55 | Young-Onset Dementias Clinic |
| Memory loss after stroke | Cerebrovascular |
| Memory loss after concussion | PM&R |
| Huntington's Disease | Huntington's Disease Center (warm transfer) |
| Dizziness/vertigo > 6 months | Vestibular |
| BPPV | PM&R |
| Concussion/TBI | PM&R |
| Ataxia due to stroke | Cerebrovascular |
| Ataxia due to MS | Neuroimmunology |
| Cerebellar ataxia (genetic) | Ataxia Center |
| Undifferentiated neurological complaint | General Neurology |
